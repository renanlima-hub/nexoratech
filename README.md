# NexoraTech - Dashboard Odontológico

Sistema administrativo odontológico desenvolvido para gerenciamento de:

* Pacientes
* Triagens
* Voluntários
* Agendamentos
* Tratamentos

Projeto acadêmico desenvolvido utilizando React + TypeScript + TailwindCSS no frontend e Java Spring Boot no backend.

---

# Tecnologias Utilizadas

## Frontend

* React
* TypeScript
* Vite
* TailwindCSS

## Backend

* Java Spring Boot
* REST API
* Banco de Dados SQL

---

# Funcionalidades

* Dashboard administrativo
* Cadastro de pacientes
* Cadastro de triagens
* Cadastro de voluntários
* Cadastro de agendamentos
* Controle de tratamentos
* Integração com API REST
* Busca e filtros dinâmicos
* Interface responsiva
* Gráficos administrativos
* Modal de cadastros
* Navegação entre abas
