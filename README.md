# NexoraTech

Sistema web desenvolvido com foco na organização de atendimentos odontológicos, utilizando tecnologias modernas de front-end.

O projeto simula um ambiente real de gestão, permitindo visualizar pacientes, status de atendimento e interação com dados de forma intuitiva.

---

## Tecnologias utilizadas

- React
- Vite
- TypeScript
- TailwindCSS
- React Router DOM
- React Hook Form

---

## Funcionalidades

- Navegação entre páginas (SPA)
- Painel interativo com:
  - Listagem de pacientes
  - Filtro por status
  - Busca por nome
  - Visual em tabela e estrutura de agenda
  - Cards com métricas
- Formulário de contato com validação
- Menu lateral (mobile)
- Interface responsiva (mobile, tablet e desktop)
