# NexoraTech

Sistema web desenvolvido com foco na organização de atendimentos odontológicos, utilizando tecnologias modernas de front-end.

O projeto simula um ambiente real de gestão, permitindo visualizar pacientes, status de atendimento e interação com dados de forma intuitiva.


## Descrição do Projeto

A **NexoraTech** é uma aplicação front-end que tem como objetivo melhorar a comunicação e a organização de atendimentos, facilitando o acompanhamento de pacientes e a gestão de processos.

A plataforma foi pensada para centralizar informações, reduzir retrabalho, melhorar a comunicação entre equipe e pacientes e tornar o atendimento mais eficiente.


## Tecnologias Utilizadas

React, Vite, TypeScript, Tailwind CSS, React Router DOM e React Hook Form.


## Funcionalidades

- Navegação entre páginas (SPA)  
- Painel interativo com listagem de pacientes  
- Filtro por status e busca por nome  
- Visual em tabela e agenda  
- Cards com métricas  
- Página de integrantes  
- Página FAQ  
- Formulário de contato com validação  
- Interface responsiva (mobile, tablet e desktop)
